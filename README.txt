HIDUP SEHAT GURU - PWA v1

Fitur:
- Checklist rutinitas harian
- Full-body workout tanpa alat
- Catatan berat badan
- Streak dan ringkasan progres
- Data disimpan lokal di perangkat (localStorage), tanpa akun/server

CARA MEMAKAI DI ANDROID:
1. Buka folder ini melalui hosting HTTPS (misalnya GitHub Pages/Netlify) atau jalankan melalui server lokal.
2. Buka index.html/URL aplikasi di Chrome Android.
3. Pilih "Tambahkan ke layar utama" / "Install app".
4. Data tersimpan di browser/perangkat tersebut.

CATATAN:
- Karena data lokal, menghapus data browser dapat menghapus data aplikasi.
- Versi v1 belum memiliki sinkronisasi cloud atau akun.
